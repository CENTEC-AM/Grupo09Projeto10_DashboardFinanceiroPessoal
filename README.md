# 💰 Dashboard Financeiro Pessoal

## 📝 Descrição do Projeto
Este projeto é uma aplicação Front-End desenvolvida como parte da avaliação do curso técnico em informática. O objetivo principal é criar a interface de um painel de controle financeiro pessoal, permitindo o registro e a visualização de receitas e despesas de forma intuitiva.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Semântica e estruturação do conteúdo.
* **CSS3:** Estilização personalizada, tipografia e micro-interações.
* **Bootstrap 5:** Framework CSS para construção do layout responsivo, sistema de grid e componentes base.
* **JavaScript:** (Estrutura planejada para manipulação do DOM e Local Storage).

## ⚙️ Instruções de Execução
Como este é um projeto estático baseado no navegador, a execução é muito simples:
1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador de preferência.
